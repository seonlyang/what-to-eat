# 오늘 뭐 먹지? 🍽️

음식 후보를 직접 입력하고 오늘의 메뉴를 무작위로 뽑는 반응형 웹앱입니다. 가입, 서버, 브라우저 저장소 없이 현재 페이지의 메모리에서만 동작합니다.

## 실행

Node.js 20.19 이상 또는 22.12 이상이 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 터미널에 표시되는 로컬 주소(기본 `http://localhost:5173`)를 엽니다.

## 검증

```bash
npm run typecheck
npm test
npm run build
```

## 주요 기능

- 후보 입력(Enter 지원), 앞뒤 공백 제거, 30자 제한, 영문 대소문자 무시 중복 검사
- 후보 목록과 개별 삭제, 실시간 후보 개수 표시
- `Math.random()`으로 모든 후보를 동일한 확률로 선택
- 약 1.8초 추첨 애니메이션과 다시 뽑기
- 추첨 중 입력 및 삭제 잠금, 모션 감소 설정 지원, 결과 음성 안내
- 새로고침 시 후보와 결과 초기화

React, TypeScript, Vite, Tailwind CSS, Lucide React로 작성했습니다. 배포 설정과 데이터 저장 기능은 포함하지 않습니다.
